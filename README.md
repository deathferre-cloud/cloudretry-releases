Download Yandex Disk files with automatic retries, resume and a persistent queue.

**[Official website](https://cloudretry.com/en) · [Русская версия](https://cloudretry.com/ru) · [Download guides](https://cloudretry.com/en/guides)**

CloudRetry is an independent Windows application for saving a local copy of your cloud files. It retries unsuccessful downloads while the process is running, preserves unfinished work and verifies completed files in a separate queue.

- Select personal folders, individual files and accessible public links.
- Resume interrupted downloads when the server supports it and the source has not changed.
- Prioritize a folder or give one file a single attempt ahead of the queue without interrupting active downloads.
- Skip folders temporarily, stop after current downloads and continue later.
- See completed and verified file counts; open local folders from the interface.

## Download and try

Download the Windows installer from **[Releases](https://github.com/deathferre-cloud/cloudretry-releases/releases/latest)**. Windows 10/11 x64 is required. The application interface is currently in Russian; the website and purchasing information are available in English and Russian.

A five-hour trial starts on the first launch and runs continuously, including time while the application is closed. No activation code is required for the trial. A license costs RUB 499, with no subscription, for one active computer. The device binding can be released for transfer.

**[License and purchasing details](https://cloudretry.com/en#pricing)**

Currently supported: **Yandex Disk on Windows**. Other cloud providers and operating systems are planned, not currently available. CloudRetry cannot restore deleted files, bypass access restrictions or retrieve data that a server never returns. It is not a Yandex product. Sign-in takes place on Yandex, with read-only access to the Disk.
